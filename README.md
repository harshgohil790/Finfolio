# 💰 FinFolio – Personal Finance Management System

A **React-based Personal Finance Management System** developed as a **Database Management Systems (DBMS)** project. FinFolio demonstrates the practical implementation of database concepts such as relational schema design, normalization, SQL operations, and data management through an intuitive user interface.

🌐 **Live Demo:** https://finfolio-yve3.vercel.app/

---

# 📖 Overview

FinFolio is designed to help users organize and manage their personal financial information digitally. The project focuses on applying core **DBMS principles** while providing a clean and responsive frontend built with React.

The application allows users to manage financial records, visualize their data, and interact with a structured relational database.

---

# ✨ Features




### 📊 Dashboard

* Simple and intuitive dashboard
* Quick overview of financial information
* Easy navigation between modules

### 🏢 Companies
* Browse a list of companies
* View the current stock price of each company
* Search and explore available stocks

### 📈 Portfolio Management
* View all stock holdings
* Track available cash balance
* Monitor overall portfolio value
* Access complete trade history

### 🗄 Database Features

* Structured relational database
* CRUD (Create, Read, Update, Delete) operations
* Data consistency through normalization
* Efficient SQL queries

### 🎨 User Interface

* Responsive React application
* Modern and clean design
* User-friendly navigation
